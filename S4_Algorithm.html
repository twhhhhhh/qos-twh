D. 線性搜尋：For Loop 尋找數值 40 (無 Break) D. Linear Search: For Loop for Value 40 (No Break)

展開檢視 Python 程式碼及解釋 Expand Python Code & Explanation 
A = [20, 18, 40, 30, 10, 5]
index = -1 

# 搜尋數值 40 的索引 (沒有 break，會搜尋最後一個出現的位置)
for i in range(0, 6):
    if A[i] == 40:
        index = i

print("數值 40 的索引為 :", index)
A = [20, 18, 40, 30, 10, 5]
index = -1 

# Search index of 40 (no break, searches for the last occurrence)
for i in range(0, 6):
    if A[i] == 40:
        index = i

print("Index of 40 is:", index)

解釋： 線性搜尋 (Linear Search) 是一種簡單的搜尋演算法。本段程式使用 for loop 依序檢查每個元素。由於沒有使用 break，程式會一直執行到列表末端。若列表中有多個相同數值，index 會保存最後一次符合條件的索引值。若找不到，則保持預設值 -1。

Explanation: Linear Search is a straightforward search algorithm. This block uses a for loop to inspect each element sequentially. Since there is no break statement, the loop will run to the very end. If there are duplicates, index will keep the last occurrence's index. If not found, it remains -1.

E. 線性搜尋：While Loop 尋找數值 40 (Flag 提早結束) E. Linear Search: While Loop for Value 40 (Early Exit via Flag)

展開檢視 Python 程式碼及解釋 Expand Python Code & Explanation 
A = [20, 18, 40, 30, 10, 5]
index = -1 
F = False

# 搜尋數值 40 的索引 (使用 flag 提早終止)
i = 0
while i < 6 and F == False:
    if A[i] == 40:
        F = True
        index = i
    i = i + 1

if F == True:
    print("數值 40 的索引為 :", index)
A = [20, 18, 40, 30, 10, 5]
index = -1 
F = False

# Search index of 40 (early exit using flag F)
i = 0
while i < 6 and F == False:
    if A[i] == 40:
        F = True
        index = i
    i = i + 1

if F == True:
    print("Index of 40 is:", index)

解釋： 此版本使用 while loop 以及布林標記變數 (Flag) F。只要找到目標值，F 就會更新為 True，迴圈判斷條件 F == False 將不再成立，從而**提早跳出迴圈**。這樣做可以避免無謂的後續搜尋，提升程式執行效率。

Explanation: This version uses a while loop combined with a boolean flag F. Once the target value is found, F becomes True. The loop condition F == False breaks, leading to an **early termination**. This avoids searching remaining elements unnecessarily, improving program efficiency.

第 2 頁：列表的元素操作 Page 2: Element Operations

初始列表設定為： Initial List: A = [20, 18, 40, 30, 10, 5]

A. 將數值 28 插入到索引 3 A. Insert Value 28 at Index 3

觀察底層運算時，後方的元素需要先向右「順延」騰出空間，才能將新數值放入指定位置。 Observe the underlying operation: elements behind must shift right to free up space before inserting the new value.

展開檢視 Python 程式碼及解釋 Expand Python Code & Explanation 
A = [20, 18, 40, 30, 10, 5]

# Python 內建方法：
A.insert(3, 28) 
print(A)

# (背後原理概念模擬)：
# A.append(0)  先擴展空間
# for i in range(5, 2, -1):
#     A[i] = A[i-1]   將元素往右移
# A[3] = 28
A = [20, 18, 40, 30, 10, 5]

# Built-in Python method:
A.insert(3, 28) 
print(A)

# (Underlying Principle Simulation):
# A.append(0)  Expand space first
# for i in range(5, 2, -1):
#     A[i] = A[i-1]   Shift elements right
# A[3] = 28

解釋： 在 Python 中，我們只需使用 .insert(index, value) 即可完成。但對電腦記憶體而言，在中間插入資料時，從該位置到結尾的所有元素都必須往後移動一格，才能騰出空位存放新資料。

Explanation: In Python, we simply use .insert(index, value). However, in terms of computer memory, inserting data in the middle requires all subsequent elements to shift backwards by one slot to create space for the new data.

B. 移除索引 2 的內容並騰空最後位置 B. Remove Element at Index 2 and Clear Last Position

觀察底層運算時，移除中間的元素後，後方的元素會向左「填補」空缺。 Observe the underlying operation: after removing a middle element, subsequent elements shift left to fill the gap.

# A.pop()             刪除最後多餘的空間

# Built-in Python method:
A.pop(2) # or del A[2]
print(A)

# (Underlying Principle Simulation):
# for i in range(2, 5):
#     A[i] = A[i+1]   Shift elements left to fill
# A.pop()             Remove extra space at the end

解釋： Python 中可以使用 A.pop(2) 或 del A[2] 刪除指定索引的元素。底層操作上，這會導致該索引後面的所有元素往前移動一格覆蓋掉目標值，並縮短陣列的長度。

Explanation: In Python, you can use A.pop(2) or del A[2]. At a lower level, this causes all elements following that index to shift forward one slot, overwriting the target value and reducing the array length.

第 3 頁：列表的進階操作 Page 3: Advanced Operations

初始列表設定為： Initial List: A = [5, 10, 18, 20, 30, 40]

A. 檢查列表是否由小至大排序 A. Check if List is Sorted in Ascending Order

展開檢視 Python 程式碼及解釋 Expand Python Code & Explanation 
A = [5, 10, 18, 20, 30, 40]
is_sorted = True

for i in range(0, 5): # 注意範圍只需到長度-1
    if A[i] > A[i+1]: # 如果前一個比後一個大
        is_sorted = False
        break # 已發現未排序，提早結束迴圈

if is_sorted:
    print("TRUE")
else:
    print("FALSE")
A = [5, 10, 18, 20, 30, 40]
is_sorted = True

for i in range(0, 5): # Note range only goes to length-1
    if A[i] > A[i+1]: # If previous is greater than next
        is_sorted = False
        break # Unsorted found, break loop early

if is_sorted:
    print("TRUE")
else:
    print("FALSE")

解釋： 要確認是否由小到大排序，我們只需比較相鄰的兩個元素（A[i] 和 A[i+1]）。如果發現任何一個左邊大於右邊的狀況，就代表未排序，可以直接判定為 FALSE 並結束檢查。

Explanation: To check ascending order, we compare adjacent elements (A[i] and A[i+1]). If we find any instance where the left is greater than the right, the list is unsorted. We set it to FALSE and break the loop.

B. 將列表內容倒轉 (Reverse) B. Reverse the List Contents

透過交換首尾兩端的元素 (前後對調) 來實現倒轉。 Reverse is achieved by swapping elements from both ends moving towards the center.

展開檢視 Python 程式碼及解釋 Expand Python Code & Explanation 
A = [5, 10, 18, 20, 30, 40]

# Python 內建方法：
A.reverse()
print(A)

# (自定邏輯：首尾交換法)
# length = len(A)
# for i in range(0, length // 2):
#     temp = A[i]
#     A[i] = A[length - 1 - i]
#     A[length - 1 - i] = temp
A = [5, 10, 18, 20, 30, 40]

# Built-in Python method:
A.reverse()
print(A)

# (Custom logic: Two-pointers swap)
# length = len(A)
# for i in range(0, length // 2):
#     temp = A[i]
#     A[i] = A[length - 1 - i]
#     A[length - 1 - i] = temp

解釋： Python 提供了方便的 .reverse() 方法。若要自己編寫邏輯，常見做法是將索引 0 與最後一個交換，索引 1 與倒數第二個交換...直到中間位置，這樣迴圈次數只要列表長度的一半。

Explanation: Python provides a convenient .reverse() method. If writing custom logic, the common approach is to swap index 0 with the last, index 1 with the second to last... stopping at the middle. Thus, loop iterations equal half the list's length.
