繁體中文

這個 3D 視覺化展示數據封包由電腦網絡介面卡出發，經過校園或家庭網絡設備，再到 ISP 和互聯網的過程。

English

This 3D visualization shows how data packets leave a computer network interface card, pass through local network devices, then reach the ISP and the Internet.

提示：封包接近裝置時會減速並閃光，表示裝置正在接收、檢查或轉發資料。
